What is Deepfake?

A deepfake is digitally generated or manipulated media created using artificial intelligence.

🔎

Check the Source

Always verify where an image came from before believing or sharing it.

⚠️

Look for Warning Signs

🌐

Use reliable sources and image-search tools to verify suspicious images.
